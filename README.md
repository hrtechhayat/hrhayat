# Habibur Rohman Hayat - Personal Portfolio

A clean, modern, professional, and student-friendly personal portfolio website for **Habibur Rohman Hayat** (`AI Dev // Full Stack // SysAdmin`), an enthusiastic student and creator from Bangladesh.

Live Domain: **[https://www.hrhayat.top](https://www.hrhayat.top)**

Built strictly using **HTML5 + CSS3 + Vanilla JavaScript Only**. Zero frameworks, zero backend, zero external build tools, zero dependencies. Runs directly by simply opening `index.html` in any web browser.

---

## 🏗️ Architecture & Technology Stack

- **HTML5:** Semantic, accessible markup with structured Person JSON-LD (`https://www.hrhayat.top/`) and complete SEO meta tags.
- **CSS3:** Custom design tokens (`style.css`), dark mode default with light mode toggle, responsive layout with Flexbox & CSS Grid, no horizontal scroll.
- **Vanilla JavaScript:** Fast, modular script (`script.js`) handling theme toggling, localStorage persistence, responsive drawer menu, active navigation indicator (ScrollSpy), and dynamic current year.
